## 1. 製品定義（MVP）

Windows用の日本語指示ブラウザ助手。  
URLを開いて情報収集したり、画面操作を支援します。  
AIが手順を分解し、1手ずつ要素を確認してから実行します。

ログインが必要なサイトは、起動したChromeに先にログインしてください。  
**事前ログインがない状態では、ログイン必須ページの操作・情報収集はできません。**

削除・購入・送信などは自動では確定せず確認します。  
すべてのサイトでの成功は保証しません。

**サイトによっては自動化・スクレイピングを禁止しています。**  
利用規約・法令を確認のうえ、**自己責任でご利用ください。**

### 補足（README / 注意事項にも記載）

- 本ツールはブラウザ操作の支援であり、サイト利用規約の遵守は利用者の責任です。
- CAPTCHA・二段階認証の突破はしません。
- 公開・商用利用の前に、対象サイトの規約を確認してください。
- Chrome拡張連携はMVP後（本アプリが本体、拡張は後付けリモコン）。

## 2. 保証範囲

### 保証する（条件付き）

- 日本語指示のステップ分解 → 1手ずつ観察・要素確定 → 実行
- URL指定の情報収集、結果の CSV / JSON ダウンロード
- 危険そうな操作の自動確定防止（確認待ち）
- **事前ログイン済み**の CDP 起動 Chrome 上での操作・収集
- いつでも Stop できること

### ベストエフォート（保証しない）

- 未知のあらゆるサイトでの高精度成功
- 複雑な SPA / 無限スクロール / iframe・Shadow DOM 多めの画面
- 同一文言ボタンが多数ある画面での完全正確な選択

### 対象外（MVPではやらない）

- CAPTCHA / 2FA の自動突破
- 未ログインでの会員限定ページ取得
- 削除・購入・送信などの完全自動確定
- 高速大量クロール用途
- 利用規約回避の支援
- Mac / Linux 版（Windows exe のみ）
- Chrome拡張（後続）

## 3. 技術方針

| 項目 | 決定内容 |
|------|----------|
| 言語・配布 | Python 製、Windows 用 exe 配布 |
| ブラウザ制御 | Playwright + CDP（`connectOverCDP`） |
| 観察 | devtools-mcp 相当の観察（要素を絞って確認してから実行）。MCP同梱は必須ではないが「観察の質」は必須 |
| LLM | ユーザー取得の Gemini API |
| Gemini SDK | **必ず公式の最新 SDK を使用する**（古いクライアントや非推奨 API に固定しない。依存更新時も最新安定版へ追従） |
| モデル分担 | **Flash**: 日本語→ステップ分解（＋必要なら再計画）。**Flash-Lite**: 1ステップの要素確定 |
| APIキー | アプリと同じディレクトリの `.env`（ユーザーが自分で取得・記入） |
| ログイン | CDPで起動した Chrome にユーザーが事前ログイン |
| プロファイル | 固定 `user-data-dir` でログイン状態を維持 |
| 拡張 | 後付け。ローカルAPIで指示を受けられる口を将来用に意識 |

### 中核ループ

```
日本語指示
  → Flash で細かいステップに分解
  → 1ステップ取り出す
  → 観察（候補要素を絞る）
  → Flash-Lite で要素確定
  → Playwright で1手実行
  → 再観察・成功判定
  → 次のステップへ（失敗時は停止 or 再計画）
```

### 危険操作ガード

- 文言・種別に基づき high risk は自動実行しない（確認UI）
- 例: 削除、退会、購入、決済、送信、振込、公開、破棄 など
- デフォルトは安全側（過剰に止まってもよい）

### 収集・出力

- 内部は構造化データで保持
- 完了後、ユーザーが CSV / JSON を選択してダウンロード
- ネストが深い場合は JSON 推奨（または主要列のみ CSV）
- CSV は Excel 向けに UTF-8 BOM を検討

## 7. 決定メモ（議論の要約）

- 拡張だけのDOM操作や、要素を大量投下して一発マッチはイマイチになりやすい。
- 成功の鍵は **観察で絞ってから要素確定 → 1手実行**。
- モデルは **分解=Flash / 要素確定=Flash-Lite** がコスパ良い。
- Gemini API は **必ず最新の公式 SDK** を活用する（古いまま固定しない）。
- 公開時は汎用受付でも、成功は条件付き保証・自己責任を明示する。
- **終了方針:** デフォルトは CDP Chrome を残す（`KEEP_BROWSER_OPEN=true` / `--close-browser` で閉じる）。
- **観察:** Playwright `page.evaluate` で操作可能要素を要約（devtools-mcp 相当。全HTMLは送らない。`OBSERVE_MAX_CANDIDATES` で上限）。
- **実行:** `ActionExecutor.run_one` は1手のみ。失敗は即停止（無限リトライなし）。`MAX_STEPS` / `POST_ACTION_WAIT_MS` で制御。
- **ループ:** 失敗時は最大1回 Flash 再計画。それでもだめなら停止。Ctrl+C / `request_stop` で中断。`ask_user` は自動継続しない。
- **安全:** `risk=high` または危険キーワードは確認必須（e/s/a）。確認UI無しなら実行しない。`COLLECT_MODE` / `--collect-mode` で書き込みブロック。
- **エクスポート:** `CollectionStore` で extract を蓄積。JSON=UTF-8 / CSV=UTF-8 BOM。0件は保存不可。
- **配布:** PyInstaller onefile。システム Chrome 利用（非同梱）。exe 横の `.env` / `.env.example`。実キーは同梱しない。
- **MVP完了:** Phase 0〜11 および受け入れ基準を満たした状態（2026-07）。
